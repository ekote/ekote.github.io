About this episode

Text from the YouTube description.

Microsoft Fabric allows you to operate notebooks, jobs, and various applications using Apache Spark within your workspace. It also offers in-depth monitoring capabilities for analyzing your job execution statistics and logs. In this episode, Estera Kot joins Jenny Jiang, the Principal Product Manager at Fabric Data Engineering, to discuss Resource Usage Analysis.
