Caching in data warehousing

Episode 30 of Fabric Espresso, the Microsoft Fabric video series created by Dr. Estera Kot.

About this episode

Text from the YouTube description.

In this video, we dive into the world of caching techniques that can supercharge your SQL query performance, especially when dealing with large datasets. Learn about the power of in-memory caching and SSD caching, two optimization techniques that can dramatically reduce query times by reducing IO latency dramatically. Whether you're a seasoned database administrator or just getting started with data warehousing in Microsoft Fabric, this video has valuable insights to help you understand how Fabric delivers great performance.
