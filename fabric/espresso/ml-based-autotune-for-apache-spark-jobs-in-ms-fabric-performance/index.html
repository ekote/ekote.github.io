About this episode

Text from the YouTube description.

In this episode of Fabric Espresso, we delve into Autotune. Estera Kot, along with Karuna Sagar Krishna and Yiwen Zhu unpack the technology, use cases and demo of Autotune – predictive optimization for Apache Spark Jobs - which automatically adjusts Apache Spark configuration to speed up workload execution and to optimize overall performance. Autotune configures three Apache Spark settings for each of your queries separately based on historical runs.

Read more: https://learn.microsoft.com/en-us/fabric/data-engineering/autotune
